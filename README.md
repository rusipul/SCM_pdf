# FedEx 인보이스 → 엑셀 변환기

FedEx 청구서 PDF 에서 선적 내역(선적일자·AWB·금액)을 뽑아 엑셀로 만들고,
PDF 에 적힌 Grand Total 과 추출 합계를 대조합니다.

실행: `python gui.py` (동결 전 기준)
